# Security and rights reports

Report suspected vulnerabilities privately to support@chimepond.com. Include the
repository and revision, affected component, impact and minimal reproduction.
Do not send credentials, private receipts, unrelated personal data or a public
exploit against the hosted service. If GitHub offers private vulnerability
reporting for this repository, that is another private reporting channel.

For copyright, licensing or withdrawal requests, use support@chimepond.com and
identify the exact record SHA-256 and the rights or removal concern. Do not post
private evidence in a public issue. Maintainers can remove current managed files
and listings; existing Git history, forks, earlier analyses and downloaded copies
may remain. A lost platform receipt does not transfer control to another account.

Repository submissions and ChimePond platform publications are distinct. A song
PR does not create a platform withdrawal receipt or establish copyright ownership.
